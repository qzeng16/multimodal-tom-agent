# Multimodal Theory-of-Mind Reasoning Agent

Interactive demo for an evidence-grounded multimodal
Theory-of-Mind reasoning pipeline built on MuMA-ToM.

The system combines:

- video frame understanding
- BLIP visual evidence extraction
- semantic multimodal retrieval
- Qwen2.5 Theory-of-Mind reasoning
- semantic option mapping
- evidence verification
- confidence estimation
- selective abstention

This Space presents a lightweight pilot demo using
precomputed outputs from the full pipeline.
